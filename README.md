# CodeAlpha Data Analytics Internship - Supermarket Sales Analysis

This repository contains the completed tasks for the CodeAlpha Data Analytics Internship, focusing on exploratory data analysis and data visualization using a Supermarket Sales dataset.

---

## 🛠️ Tools & Technologies Used
* **Python (Pandas, NumPy):** Data cleaning and Exploratory Data Analysis (EDA).
* **PostgreSQL / SQL:** Running queries for data extraction and aggregation.
* **Tableau:** Designing interactive dashboards and visual representations.

---

## 📋 Task Details

### Task 2: Exploratory Data Analysis (EDA)
* **Dataset:** Supermarket Sales Dataset (`supermarket.csv`).
* **Activities:** 
  * Cleaned and preprocessed raw data using Python.
  * Executed SQL queries to extract key sales metrics and patterns.
  * Identified trends, product category performances, and customer purchasing behaviors.

### Task 3: Data Visualization
* **Activities:**
  * Transformed processed data into an interactive Tableau dashboard (`supermarket_sales_dashboard.twb`).
  * Designed visual charts and graphs to highlight revenue trends, branch performance, and profit margins.
  * Included a clean layout image output (`Supermarket_Sales_Dashboard.png`) for quick preview.
